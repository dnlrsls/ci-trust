# 0.1.0 — draft release notes

**Status: UNRELEASED.** This document prepares the intended full-MVP release;
it does not narrow that scope to bypass [issue #9](https://github.com/dnlrsls/ci-trust/issues/9).
No release date, version tag, published binaries or completed-MVP claim is made.

## Implemented scope

- Offline, read-only `audit` of bounded Go/npm declarations and GitHub Actions
  configuration; configured coverage is not observed execution or enforcement.
- Saved schema-v1 reports with JSON and human rendering, scoped evidence and
  explicit UNKNOWN/UNVERIFIABLE outcomes; no aggregate green trust score.
- Conditional `bootstrap --dry-run` proposals, with no workflow application or
  automatic fixes.
- Public `verify PATH --check lint` reporting behind a closed execution gate.
  Its valid unresolved report exits 0; this is not a lint PASS.
- Internal owned-fixture lint workflow, exact-review binding, artifact delivery,
  independent consistency inspection, fixed runner and receipt classification
  source. These implementations do not establish runtime admission or real lint
  sensitivity by themselves.
- [MIT source license](../../LICENSE), copyright (c) 2026 dnlrsls. Third-party
  components retain their own licenses; no complete third-party distribution
  license review is claimed here.

See the [CLI contract](../cli.md), [evidence semantics](../evidence-semantics.md)
and [manual lint workflow control](../lint-workflow-control.md) for exact limits.
The development binary remains `dev` unless its build explicitly sets a version;
these notes do not change binary versioning.

not lint sensitivity evidence. No runtime was executed to prepare these notes.
